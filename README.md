# 🚫 NoDistraction YouTube (Shorts Blocker)

A lightweight and completely free browser extension that **completely removes** annoying Shorts from the YouTube interface. Get your focus and productivity back!

## ⚡️ Features
- **Works locally:** No servers, data collection, or hidden ads.
- **Zero overhead:** Optimized code that doesn't slow down YouTube.
- **Completely free:** No subscriptions or registration required.

---

## 🚀 How to install in 1 minute

Since the extension is completely independent, it is installed manually (via Developer Mode). It's safe and takes less than a minute:

1. At the top of this page, click the green **`< > Code`** button, then select **`Download ZIP`**.
2. Unzip the downloaded archive (`NoShorts-main.zip`) to any convenient folder on your computer.
3. Open your browser (Chrome, Edge, Brave, or Opera) and type this into the address bar: 
   👉 `chrome://extensions/` 
4. In the top right corner, toggle on **"Developer mode"**.
5. In the top left corner, click the **"Load unpacked"** button.
6. Select the `NoShorts-main` folder you unzipped in step 2.

**🎉 Done!** Go to YouTube — the Shorts tab and the short video feed are gone forever.
